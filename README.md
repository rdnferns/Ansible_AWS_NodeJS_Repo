# Ansible_AWS_NodeJS_Repo
It is a repository that has two exercises about deploying NodeJS on an amazon ec2 instance using ansible, ansible is a tool primarily used for configuring a enviroment on cloud infrastructures services like AWS, GCP, Azure, etc. It is quite a useful tool in the tech field mainly among DevOps professionals.

<br><br><br>

# 1) Prerequisites:
- Linux OS (distro or VM, will need bash for the other tools)
- GitHub account.
- AWS management console account.
- AWS CLI installed in your system.
- An AWS access key & secret key to configure your AWS CLI.
- A private SHA Key pair for ssh access to instances.
- Ansible installed in your linux ecosystem for configuring cloud infrastructure.
- Terraform installed for building AWS Cloud infrastructure.
